# git/ — Ảnh chụp commit của từng thành viên

Yêu cầu nộp bài: thư mục chứa **hình ảnh các commit của từng thành viên** (dùng để chấm điểm đóng góp Git).

```
git/
├── commit-screenshots/
│   ├── <ten-thanh-vien-1>.png
│   ├── <ten-thanh-vien-2>.png
│   └── ...
└── README.md
```

Đề xuất đặt tên file: `<ho-ten>_<so-luong-commit>.png`, ví dụ `nguyen-van-a_12-commits.png`.

Ảnh nên chụp rõ: tác giả commit, ngày, message, và danh sách commit trên GitHub/GitLab.
